# `MainPlayer.ets`界面说明文档

> 这个界面作为本项目的正式播放界面，会在进入的时候根据进入的按钮绑定param开始运动播放功能

## 界面介绍

界面由四大部分构成，分别为：

- 核心数据展示区（由Row和囊括的三个Column组件构成，分别用于展示BPM、运动时间、歌曲倍速。绑定的变量为`this.BPM_now`,`this.sport_time`,`this.Speed`）
- 歌曲展示区（为Column组件，内包含歌曲已播放时间、歌曲剩余时间、歌曲名和歌曲作者。绑定的变量为`this.songTimePass`,`this.SongTimeLast`,`this.SongName`,`this.Artist`）
- 侧边悬浮窗（为Column组件，吸附边缘并可拖动调整位置，包含对音乐的控件：下一首、暂停/播放、上一首，以及一个可以控制歌曲播放进度的摇杆，关于摇杆的详细说明见下文。绑定的方法为`NextSong`,`pause`,`FormalSong`）
- 底层进度条（用于展示歌曲播放进度的进度条，相关组件属性为`.linearGradient({ angle: 0, colors: [['#ffee3939', 0.0], ['#ffee3939', 0.5],['#A78BFA', 0.5],['#A78BFA', 1.0]] })`，是一个通过`clipShape`裁剪得到的双色圆形，通过旋转组件来展示歌曲的播放界面，详细说明见下文）

## 还需要你补充或修改的功能

1. 核心数据展示区有一个`Slider`组件，用于表示**选中总歌单时长下的播放进度**，并且不能被用户滑动。
2. 歌曲展示区的展示歌曲名和歌曲作者的组件可能出现内容过长的问题，需要你在内容过长的前提下将内容的展示变为滚动，滚动字符串的长度不得超过组件边界。
3. 标题处的**正在运动**可以根据当前算法加速和减速的过程每隔一秒替换为`this.Status`中的**加速中，暂停，减速中**
4. 关于摇杆的修改内容见下文
5. 关于播放进度条的修改内容见下文

## 播放进度条详细说明

摇杆组件通过旋转的方式展示播放进度，通过数学方式计算旋转的初始位置恰好指向屏幕左边缘，歌曲播放完后组件的旋转角度恰好指向屏幕右边缘，歌曲播放结束后再次指向左边缘。同时组件边缘有发光动效，会随歌曲分析的重拍变化

### 存在的问题

> 播放进度条的旋转角度没能够正确指向左边缘，而且最后歌曲播放结束（`this.SongTimeLast`归零）后也没能指向屏幕右边缘。需要你进行问题排查和修复，同时组件边缘的发光动效变化没有实现

## 摇杆组件详细说明

摇杆组件通过`this.rocker_offset`实现歌曲进度的调整，调整速度的快慢由`this.rocker_offset`的倍率决定，范围为-6到8，默认值为1。
